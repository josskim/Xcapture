## 2026-11-09 - 스크롤 캡처 및 XViewer 이미지 도구

### 요청

- 스크롤 캡처와 기본 단축키 Ctrl+Shift+D, 메인 화면 버튼 정리.
- 여러 이미지를 원본 크기로 세로로 이어 붙이거나 여러 페이지 PDF로 저장하고 이미지 순서를 변경.
- 이미지 크기, 형식, JPEG 품질 변경 및 이미지 뷰어 이름 XViewer로 변경.

### 결과

- 스크롤할 내용 영역을 드래그하면 자동 스크롤과 겹침 검사를 통해 이미지를 생성한다. 고정 메뉴, 애니메이션 등으로 겹침을 찾지 못하면 부분 캡처를 안내한다.
- 선택 이미지 순서를 위·아래로 조정하고 JPEG/PNG 합성 또는 페이지별 PDF로 저장한다.
- 크기와 비율, 출력 형식 및 JPEG 품질을 지정하여 원본과 별도 파일로 저장한다.
- 메인·뷰어 버튼을 정리하고 버전을 1.0.19로 변경한다.

### 검증

- 합성 테스트에서 1000×1000 이미지 네 장의 순서와 1000×4000 결과, 이미지 크기 변환을 확인했다.
- 생성한 PDF를 pdfinfo로 검사해 4페이지를 확인했다.
- 스크롤 겹침 검출을 합성 프레임으로 검증했다. 화면 환경과 고정 요소에 따라 실제 캡처 결과는 달라질 수 있다.
- XViewer의 창 이름과 추가 버튼을 접근성 정보로 확인했다. 테스트 창 스크린샷 도구는 시간 초과되어 시각 확인하지 못했다.
- Release 빌드, self-contained publish 및 Inno Setup 설치파일 생성 성공.
- GitHub 최신 릴리스 API에서 `v1.0.19` 및 `XCaptureSetup.exe` asset과 로컬 설치파일 크기를 확인했다.

### 커밋

- 기능 커밋 및 릴리스 태그 대상: `b4b279a`

## 2026-11-09 - 브라우저 전체 너비 스크롤 캡처 및 합치기 미리보기

### 요청

- 선택한 좁은 사각형이 아니라 선택한 브라우저의 스크롤 화면 전체를 캡처한다.
- 이미지 합치기에서 사진을 보면서 순서를 바꾸고 다른 이름으로 저장한다.

### 결과

- Chrome/Edge 페이지의 렌더링 영역을 찾아 전체 너비로 맨 위부터 캡처하고, 선택한 지점을 스크롤 대상으로 사용한다.
- 고정 사이드바와 상단 영역을 제외해 스크롤 겹침을 비교한다. 인식하지 못한 브라우저는 안내 후 중지한다.
- 이미지 합치기 화면에 썸네일, 선택한 이미지의 큰 미리보기 및 다른 이름으로 저장 버튼을 추가한다.
- 사용자 첨부 화면과 고정 사이드바를 이용한 합성 프레임으로 겹침 계산을 검증했다.
- 테스트 창의 컨트롤과 썸네일·미리보기는 접근성 트리로 확인했다. 화면 캡처 도구가 시간 초과되어 실제 브라우저 캡처의 시각 검증은 하지 못했다.
- Release publish와 Inno Setup 설치파일 생성에 성공했다.
- GitHub 최신 릴리스 API가 `v1.0.20`과 `XCaptureSetup.exe`를 반환하고 asset 크기가 로컬 파일과 일치함을 확인했다.

### 커밋

- 기능 커밋 및 릴리스 태그 대상: `8683a33`

## 2026-11-09 - 캡처 편집 창을 XViewer로 통합

### 요청

- 캡처한 이미지를 보는 별도 창의 상단 기능을 XViewer에 통합한다.
- 설치 시 이미지 파일 우클릭 메뉴 등록 체크박스를 기본 선택한다.

### 결과

- 새 캡처, 캡처 목록, 일반 이미지가 동일한 XViewer에서 열린다. 펜, 지우개, 색상·굵기, 되돌리기·초기화, 복사·저장·인쇄와 캡처 목록을 제공한다.
- 편집 내용이 있는 상태에서 다른 이미지를 열거나 이동·종료할 때 저장 여부를 묻는다. 새 캡처를 취소하더라도 캡처 이력은 보관한다.
- 이미지 우클릭 등록 옵션을 신규 설치 및 기존 설치의 작업 선택 화면에서 기본 체크한다. 사용자의 수동 해제와 명시적 설치 작업 인수는 유지한다.

### 검증

- 독립 WPF 테스트에서 XViewer 열기, 펜 획 합성·원본 크기 보존, 미저장 표시, 되돌리기 및 같은 창에서 이미지 이동을 확인했다.
- XViewer의 편집·복사·저장·인쇄·목록·기존 이미지 도구가 접근성 트리에 표시됨을 확인했다. 화면 캡처 도구 시간 초과로 실제 화면의 시각적 배치는 확인하지 못했다.
- Release publish 및 설치파일 컴파일에 성공했다. 설치 선택 체크박스는 설치 스크립트와 컴파일을 확인했으며 설치 마법사 화면에서 실측하지 못했다.
- GitHub 최신 릴리스 API가 `v1.0.21`과 `XCaptureSetup.exe`를 반환하고 asset 크기가 로컬 파일과 일치함을 확인했다.

### 커밋

- 기능 커밋 및 릴리스 태그 대상: `7df2ade`
