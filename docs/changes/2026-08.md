## 2026-08-27 - 이미지 뷰어 및 Windows 이미지 연결 추가

### 요청 원문

> 우리 dev>Xcapture 프로그램 있잖아.  
> 이미지 뷰어 기능도 할수있도록해줘. 이미지 우클릭했을때 프로그램연결할수있도록 메뉴에 등록 할수있도록해주고, 이미지 설치시 이미지 뷰어 자동 연결도 되도록.

### 결과 요약

- PNG, JPEG, BMP, GIF, TIFF 파일을 직접 여는 XCapture 이미지 뷰어를 추가했다.
- 창 맞춤, 1:1, 확대/축소, 이전/다음 이미지, 복사, 편집, 파일 위치 열기, 드래그 앤 드롭을 지원한다.
- 이미지 파일 인수로 실행했을 때 기존 XCapture 프로세스에 파일 경로가 전달되도록 단일 실행 통신을 명명 파이프로 변경했다.
- Windows `연결 프로그램`과 이미지 우클릭 메뉴의 `XCapture로 보기`가 설치 시 자동 등록되도록 했다.
- Windows 10/11의 보호된 기본 앱 선택 정책을 준수해 기존 기본 이미지 앱은 강제로 변경하지 않는다.
- 버전을 `1.0.17`로 올리고 설치파일 `Installer/XCaptureSetup.exe`를 다시 생성했다.

### 검증

- `dotnet build -c Release` 성공 (경고 0, 오류 0)
- `dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -o publish-latest` 성공
- 이미지 파일 인수로 뷰어가 열리고 파일명, 해상도 및 폴더 내 이전/다음 항목이 로드되는 것을 확인했다.
- 두 번째 XCapture 실행에 다른 이미지 경로를 넘겼을 때 프로세스가 1개로 유지되고 기존 뷰어가 새 파일로 전환되는 것을 확인했다.
- Inno Setup 6.7.3으로 `Installer/XCaptureSetup.exe` 생성 성공
- 자동 설치 후 파일 버전 `1.0.17.0`, `OpenWithProgids`, `SupportedTypes`, `XCapture로 보기` 레지스트리 등록을 확인했다.
- 설치된 `XCapture.exe`에서 이미지 뷰어 실행을 확인했다.
